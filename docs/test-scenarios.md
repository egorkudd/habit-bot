# Поведенческие сценарии

Тесты, где «живой» пользователь пишет боту, нажимает кнопки, ошибается, отвлекается и возвращается —
в поддельном Telegram, с поддельными часами и перезапусками бота (`tests/scenarios`, отметка `scenario`).
Запуск: `pytest -m scenario`. Каталог собирается из описаний тестов: `python scripts/gen_scenarios_doc.py`.

| № | Сценарий | Тест |
|---|---|---|
| S-01 | Незнакомец без ссылки пишет /start, текст, стикер, жмёт старую кнопку — всегда «по приглашению», в базе ничего не появляется. | `test_access.py::test_s01_stranger_is_turned_away` |
| S-02 | Владелец приглашает близкого: ссылка из «Админ» → гость проходит анкету с «Заполнить позже» → у гостя меню без «Админ», у владельца приглашение исчезло из списка. | `test_access.py::test_s02_invited_relative_joins` |
| S-03 | Одноразовую ссылку переслали дальше: второй человек получает «все места уже заняты». | `test_access.py::test_s03_one_time_link_cannot_be_reused` |
| S-04 | Владелец передумал и отозвал ссылку до того, как ей воспользовались — вход закрыт. | `test_access.py::test_s04_revoked_link` |
| S-05 | Ссылку на 1 день открыли через 2 дня — «истекла дд.мм». | `test_access.py::test_s05_link_expires` |
| S-06 | Гость удалил аккаунт, затем пишет снова — «по приглашению»; по новой ссылке начинает с чистого листа. | `test_access.py::test_s06_owner_comes_back_after_deleting_guest` |
| S-07 | Владелец впервые пишет боту: анкета целиком → норма 2800/160/80/360 → меню → /start — приветствие. | `test_onboarding.py::test_s07_owner_first_run` |
| S-08 | Человек ошибается: буквы вместо роста, «1780», будущая дата рождения — подсказки, шаг не теряется; «← Назад» исправляет прошлый ответ. | `test_onboarding.py::test_s08_typos_and_back` |
| S-09 | Посреди анкеты человек жмёт «отмена», /cancel, пишет «🍽 Еда», шлёт стикер — анкета напоминает вопрос, ничего не сбрасывается. | `test_onboarding.py::test_s09_tries_to_escape` |
| S-10 | Человек листает вверх и жмёт кнопку прошлого шага — бот повторяет текущий вопрос. | `test_onboarding.py::test_s10_old_buttons_in_onboarding` |
| S-11 | Бросил анкету на 6-м шаге, бот перезапускался, вернулся через сутки — продолжает с того же шага. | `test_onboarding.py::test_s11_comes_back_next_day_after_restart` |
| S-12 | Два человека проходят анкету одновременно, ответы чередуются — данные не смешиваются. | `test_onboarding.py::test_s12_two_people_at_once` |
| S-13 | Человек нажимает все кнопки меню подряд: разделы, которых ещё нет, отвечают «скоро» с номером части; непонятный текст и стикер — подсказка с меню. | `test_everyday.py::test_s13_walks_through_menu` |
| S-14 | Начал ввод, ушёл на 20 минут, вернулся и нажал кнопку старого вопроса: «Это меню устарело», бот за это время ничего не присылал, число теперь не ждётся. | `test_everyday.py::test_s14_left_for_coffee` |
| S-15 | Пауза 10 минут, затем бот перезапустился, ещё 3 минуты — ввод продолжается с того же шага. | `test_everyday.py::test_s15_short_pause_keeps_input` |
| S-16 | Двойное нажатие «✅ Готово» (Telegram доставил нажатие дважды): одно «Готово», второе — «устарело». | `test_everyday.py::test_s16_double_tap` |
| S-17 | Отмена кнопкой, словом и командой; повторная отмена — «Отменять нечего». | `test_everyday.py::test_s17_cancel_three_ways` |
| S-18 | Гость нажимает кнопку с данными владельца (подмена) — отказ, ввод владельца не тронут. | `test_everyday.py::test_s18_forwarded_button` |
| S-19 | Вечером вспомнил про вчера: «Другой день» → «Вчера» → «Выходной» за вчера → «Вернуться к сегодня». | `test_everyday.py::test_s19_forgot_yesterday` |
| S-20 | Включил «Другой день» и забыл: через 15 минут режим выключен молча; старая кнопка «Вернуться» — «Вы и так в сегодняшнем дне», клавиатура обычная. | `test_everyday.py::test_s20_other_day_forgotten` |
| S-21 | Сова отмечает выходной в 00:20 — он попадает во вчерашний день; в 04:05 — уже в новый. | `test_everyday.py::test_s21_night_owl` |
| S-22 | Похудел на весах: вес 80 → «Пересчитать»; потом рост 190 → «Оставить как есть»; цели — история. | `test_settings_and_failures.py::test_s22_weight_changed_then_hesitates` |
| S-23 | Начал менять вес, отвлёкся на 15 минут, потом ввёл число — оно уже не принимается за вес. | `test_settings_and_failures.py::test_s23_starts_edit_and_walks_away` |
| S-24 | Единственный администратор пытается удалить аккаунт — отказ с подсказкой, данные на месте. | `test_settings_and_failures.py::test_s24_only_admin_cannot_leave` |
| S-25 | Пользователь заблокировал бота: ответы не доходят, но бот не падает и продолжает работать. | `test_settings_and_failures.py::test_s25_user_blocked_the_bot` |
| S-26 | Сервис поиска городов не отвечает — бот объясняет и предлагает кнопки; город можно выбрать кнопкой. | `test_settings_and_failures.py::test_s26_city_service_down` |
