# Ход разработки habit-bot

Репозиторий: `egorkudd/habit-bot` (приватный, защита `main` не включается — требования, ред. 10).
Бот в Telegram: @daily_habbit_bot. Сервер: HOSTKEY, Ubuntu 24.04.5, Docker 29.1.3.
Все части ведутся в одной сессии по очереди; следующая — после приёмки предыдущей владельцем.
После каждой части все документы (требования, архитектура, диаграммы, этот отчёт) обновляются
и выгружаются в папку `docs/` репозитория — правило в `CLAUDE.md` и в разделе 8.1 требований.

  Фоновая задача раз в минуту и при старте (`kernel/jobs.py`, `JobSpec`).
- `CallbackGuardMiddleware`: кнопки несут владельца `o` и номер ввода `t`; чужая — `ACCESS-FOREIGN`, устаревшая — `UI-STALE`.

Решения и находки:
- Встроенное хранилище aiogram выключено (`disable_fsm=True`), `state` и `raw_state` кладёт `ActivityMiddleware` —
  так ключ строится по пользователю бота, а не по Telegram-ID.
- Номер ввода (`token`) — случайное число в строке `DialogState`. Новый ввод (`start_dialog`) получает новый номер,
  поэтому кнопки прошлого ввода устаревают сразу, а не только через 15 минут.
- Переход в раздел главного меню закрывает незаконченный ввод — иначе «🍽 Еда» принималось бы за ответ на вопрос.
- Модуль, подключая раздел, вызывает `menu.mark_ready(key)` и обрабатывает кнопку своим роутером.
- Для `workout` (часть 8) к сбросу добавится автозавершение тренировки, для `other_day` (часть 4) — отметка
  для «📅 Нет, за 24.10». Сейчас просроченные строки просто удаляются.
- Часовой пояс — `ZoneInfo("Europe/Moscow")`, в образ добавлен пакет `tzdata`.

## Правки интерфейса (версия 0.6.2, PR #12 слит и выложен 05.11.2026), ждёт проверки в Telegram

Отдельный PR параллельно разработке — по замечаниям владельца после проверки на телефоне.

Что сделано:
- **Кнопки помещаются.** Bot API не сообщает ширину, а клиент делит ряд поровну и обрезает подпись многоточием.
  Бюджет посчитан по ширине узкого телефона и сверен с жалобой («Отжимания» не влезло в ряд из трёх): примерно
  30 знаков на кнопку в ряду из одной, 15 — из двух, 8,5 — из трёх (эмодзи — 2 знака). `ui/layout.py`: `fit_rows`
  кладёт в ряд столько кнопок, сколько помещается; `inline()` делит ряд, если подпись в нём обрежется. Поддельный
  Telegram в тестах теперь падает на обрезанной подписи — так нашлись и исправлены ещё 8 экранов (уровень опыта,
  «Позавчера (23.10)», «🏠 Главный экран» + «📦 Экспорт», «🔄 Пересчитать по профилю», «Оставить как есть»,
  «🗑 Да, удалить всё», заголовок календаря «Октябрь 2026», «👥 Пользователи»).
- **Еда:** под карточкой «×0,5» «×2» / «Отменить» «📅 На вчера».
- **Зарядка:** упражнения столбиком; без «Как в прошлый раз» (черновик и так со значениями прошлой зарядки,
  «Записать» — одно нажатие); «Изменить» — «Отжимания −5» / «Отжимания +5»; все значения одной строкой
  `55 50 6:15 25`; в наборе у каждого упражнения своё меню «✏️ Шаг» / «⬆ Выше» / «✕ Убрать».
- **«🏠 Домой»** рядом с «☰ Ещё»: выход из ввода и удаление его сообщений; бот ничего не пишет.
- **Чистый чат:** вопросы и ответы по ходу ввода удаляются, когда показан итог; итоги остаются. Замена карточки
  удаляет старую.
- **«☰ Ещё»** показывает разделы, убранные с главного экрана.
- Сценарии S-54…S-61, обновлены S-42…S-51. Требования — редакция 11.

Решения и находки:
- Сообщение, которое принесло клавиатуру внизу, не удаляется, пока не пришло следующее с клавиатурой:
  на части клиентов удаление такого сообщения прячет клавиатуру.
- След хранится в базе (область `trail`) 48 часов — переживает перезапуск; старше Telegram удалить не даст.

- Прогон критериев нашёл расхождение: в заполнении через ИИ группы («Рецепты: 4») показывались только для карточек

## Правки 1.0.2 (PR #20) — ждут «Сливай»

- «🏠 Домой» очищает всю переписку. Историю чата бот прочитать не может, а номера сообщений в личных чатах Telegram
  общие для всех чатов пользователя — удаление «диапазоном номеров» не годится. Поэтому бот ведёт журнал номеров

  сообщения удалить не даст, а удалённые пользователи пропадают из журнала сами.
- Цель «тренировок в неделю» от 1; еда / зарядка / тренировка — только в «✅ Привычки»; спрятаны «📝 Текстом»,

  последних 04:00 по Москве, кроме файлов и последнего сообщения с клавиатурой (иначе клиент Telegram может спрятать
  клавиатуру — поэтому в журнале есть отметка «с клавиатурой»). Без отдельной отметки «когда чистили»: задача
