# Приёмка MVP: критерии раздела 9 и их проверки

Полный прогон критериев MVP из раздела 9 требований (часть 10). Для каждого критерия указано, какой автотест его
проверяет; S-xx — поведенческий сценарий в поддельном Telegram (каталог — `docs/test-scenarios.md`). Пометка 🖐 —
проверяется руками или живыми сценариями GitHub Actions: Telegram, сервер, телефон (`docs/manual-testing.md`).

Итог прогона (06.11.2026, версия 1.0.0): все автотесты зелёные; критерии v2 и v3 в MVP не входят.
